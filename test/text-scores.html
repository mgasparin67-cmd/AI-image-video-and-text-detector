Text scores

Scores every text in ?data=FILE.json ({ set: [texts] }) with the extension's two text checks, as content.js does: the text model (models.js) and the writing patterns (text-detector.js). For evaluations: node test/run-all.mjs "text scores" --save DIR writes the scores to DIR/<name>.json. &normalize=1 cleans each text first (AIBText.normalize); each score also records the genre checks.
